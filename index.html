TapeGuard Receipts

Run four TapeOut guard circuits live on X Layer mainnet and anchor a verifiable receipt of the result.

1. Set the 16 input bits

Each bit is one risk flag in your agent or trading-bot profile. Presets: Safe profile = all bits off. Risky profile = all bits on.

Input bytes: 0x0000

2. Evaluate on X Layer mainnet

Calls eval(circuitId, input) on TapeOut processor 0xb57b56034e2dc25161e2512CfC40b24EA3bee1Fb (ViperX Risk Guardian, circuits 1–4) via the public X Layer RPC. Read-only: no wallet, no gas.

3. Receipt

The receipt payload binds processor, input, outputs and mainnet block. Anchoring stores the keccak256 receipt hash computed by TapeGuardRegistry on X Layer testnet; anyone can recompute it from the same payload fields.
